# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run dev        # dev server (requires ampx sandbox running first)
npm run build      # type-check + build
npm run lint       # ESLint

npx ampx sandbox          # start Amplify backend sandbox (first run: 3-5 min)
npx ampx sandbox delete   # tear down AWS resources
```

No test suite. `amplify_outputs.json` is auto-generated by `npx ampx sandbox` and required for local dev.
